## What this notice does and does not do

This file is a **claim of use**, not a registration. It records that the name is
in use and gives you dated evidence of first use, which is what matters when
someone else applies to register a conflicting mark.

It does **not** by itself give you enforceable exclusive rights in the way a
registered trademark does. For that you must register.

## Recommended registration

For commercial use in Nigeria and for shipping to colleagues, file:

| Route | Where | Why |
| --- | --- | --- |
| **National** | Trademarks Registry, Commercial Law Department, Federal Ministry of Industry, Trade and Investment (Nigeria) | Cheapest and fastest first filing. Class 9 (software) and Class 42 (SaaS / software services). |
| **Regional** | ARIPO or OAPI, if you expand across Africa | One filing, multiple states. Nigeria is neither an ARIPO nor an OAPI member, so this is in addition to, not instead of, a Nigerian filing. |
| **International** | WIPO Madrid System | One application covering many countries. Requires a home filing or registration first, so do the Nigerian filing before this. |

Filing in **Class 9** (downloadable software) and **Class 42** (software as a
service) is the usual combination for an app. Use a registered trademark agent —
the registry will not give you legal advice on class selection or on whether the
mark is already taken.

## Before you file: search first

1. Search the Nigerian trademark register for "KeshScan" and for similar marks
   (Kesh, Scan, Kesh Scan) in classes 9 and 42.
2. Search the web, the App Store, Google Play and GitHub for existing "KeshScan"
   use.
3. Search WIPO Global Brand Database if you intend to export.

**This matters:** a name already used by another party can be blocked even if you
started using it independently. "Kesh" is the distinctive part of the mark, so
the search should focus on that, not on "Scan", which is descriptive and
therefore weak on its own.
